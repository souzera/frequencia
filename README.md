# Frequência — aplicativo desktop para MP3

Aplicativo pywebview com tema claro, Cascadia Code, links individuais e playlists de YouTube e Spotify, seleção de faixas e configurações de pasta e qualidade.

Leia o [guia desktop](README-DESKTOP.md) para executar, testar e empacotar o aplicativo.

Entrada principal: `desktop_app.py`. Dependências: `requirements-desktop.txt`.
